# El Archivo del Tiempo

A narrative adventure game developed in **Unity** over four months by a team of six students as a university project. The game combines visual novel storytelling with interactive gameplay through exploration, inventory management, and two original minigames.

**Role:** Lead Programmer
**Engine:** Unity
**Language:** C#
**Development Time:** 4 months

---

## About the Game

*El Archivo del Tiempo* is a story-driven game where players uncover the mysteries of a forgotten archive by exploring locations, collecting items, and interacting with characters through branching dialogue.

The final project was presented to a university judging panel and received the **Best Art** award.

---

## My Contributions (Lead Programmer)

I was responsible for the implementation of the game's core gameplay systems and worked as the lead programmer within a six-person development team.

### Gameplay Systems

* Designed and implemented a custom **dialogue system** in Unity.
* Added a **typewriter text animation** for dialogue.
* Implemented an **inventory system** for collecting and using items.
* Developed a **rhythm-based minigame**.
* Developed a **memory minigame**.

### UI Systems

* Dialogue interface.
* Inventory interface.
* Map interface.
* Pause menu.

### Development Responsibilities

* Collaborated with the team using **Git** for version control.
* Maintained and integrated gameplay systems into the project.
* Worked closely with designers and artists to connect gameplay with narrative content.
* Evaluated game features for the web release, including removing the save/load system because it was unnecessary for the browser version.
